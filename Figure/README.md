## Figure/

The `Figure/` folder stores the output figures generated by the simulation and real-data analysis scripts. These figures include:
- plots used to summarize simulation results (Section 7), and
- plots from the real-data analyses (Section 8), including the COVID-19 and EHR applications.

Running the corresponding scripts (e.g., `Simulation_result.R`, `Data_analysis_COVID19.R`, and `Data_analysis_EHR.R`) will automatically generate and save the figures to this folder.
